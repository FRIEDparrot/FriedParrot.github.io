3. Markov Chain & Markov Sampling

1. Markov chains ​

(1) State transition probability ​

Markov property The next state depends only on the current state, not on the past states.

Let (Xt)t≥0 be a discrete-time Markov chain on a state space S={a1,a2,…}. It satisfies the Markov property:

(1.1.1)Pr(Xt+1=j∣Xt=i,Xt−1,…,X0)=Pr(Xt+1=j∣Xt=i).

Thus, conditional on the current state, the next state is independent of the earlier history. For a time-homogeneous chain, this conditional probability does not depend on t. Define the one-step transition probabilities and transition matrix by

(1.1.2)Pij=Pr(Xt+1=aj∣Xt=ai),P=(Pij).

This note uses the row-vector convention: row i gives the probabilities of moving from ai to the possible next states. Therefore,

(1.1.3)Pij≥0,∑jPij=1.

For example, a finite-state transition diagram may be represented by the matrix P, whose entry Pij is the label on the directed edge ai→aj.

(2) Multi-step transition probabilities ​

We define ==the n-step transition probability== as :

(1.2.1)pij(n)=Pr(Xt+n=aj∣Xt=ai).

Let P(n)=(pij(n)). The Chapman-Kolmogorov equation (C-K equation) is defined as the transition probability relation on state transition i-> k -> j summed on every possible intermediate states k :

(1.2.2)pij(m+n)=∑k∈Spik(m)pkj(n).

pij(m+n)=Pr(Xt+m+n=aj∣Xt=ai) is the probability that the chain reaches state aj after m+n steps, given that it starts at ai.

In particular, for a time-homogeneous chain, it satisfies the Markov condition, the relation of :

(1.2.3)P(n)=Pn,pij(n)=∑k∈SPikpkj(n−1).

Equivalently, expanding over all intermediate states gives :

(1.2.4)pij(n)=∑k1,…,kn−1∈SPik1Pk1k2⋯Pkn−1j.

If the initial distribution is the row vector μ0, then the distribution after n steps is

(1.2.5)μn=μ0Pn.

(3) Limiting distribution ​

A distribution π is a limiting distribution of state transformmatrix P when

(1.3.1)limn→∞μ0Pn=π

for every initial distribution μ0. For a finite Markov chain, irreducibility and aperiodicity are sufficient for a unique limiting distribution. More generally, suitable recurrence conditions are also required on an infinite state space.

2. Stationary distributions and detailed balance ​

(1) Stationary distribution ​

A probability distribution π=(π1,π2,…) is stationary for P if :

(2.1.1)πP=π,∑iπi=1,πi≥0.

Component wise, the stationarity condition is :

(2.1.2)πj=∑iπiPij.

If a chain is initialized from π, it remains distributed as π after every transition. In MCMC, π is the target distribution; after convergence, the chain states can be used as dependent samples from π.

(2) Detailed balance ​

To make sure a distribution is a stationary distribution, A convenient sufficient condition for stationarity is detailed balance (or reversibility) :

(2.2.1)πiPij=πjPjifor all i,j.

Indeed, summing over i and using ∑iPji=1 gives

(2.2.2)∑iπiPij=∑iπjPji=πj.

Detailed balance is sufficient, but not necessary, for π to be stationary.

3. Markov Chain Monte Carlo (MCMC) ​

MCMC constructs a Markov chain whose stationary distribution is a chosen target density or mass function π(x). It is especially useful when direct independent sampling from π is difficult, while evaluating π(x) up to a normalizing constant is feasible.

Starting from an arbitrary initial state X0=x0, run a transition kernel that leaves π invariant. After a suitable burn-in period, retain states Xt as samples. Because consecutive states are correlated, effective sample size is generally smaller than the number of retained iterations.

Target density need not be normalized In Metropolis-Hastings, only ratios such as π(y)/π(x) are used. Hence one may use an unnormalized target π~(x)=cπ(x) when the normalizing constant c is unknown.

4. Metropolis-Hastings sampling ​

(1) Introduction ​

Let q(y∣x) be a proposal distribution, if we want to sample from this distribution, we can use the

given the current state x, it generates a candidate y. The Metropolis-Hastings (MH) algorithm is to accept/reject a sample by the probability :

  1. Set X0=x0.
  2. Given Xt=x, propose Y∼q(⋅∣x).
  3. Compute the acceptance probability :
(4.1.1)α(x,y)=min{1,π(y)q(x∣y)π(x)q(y∣x)}.

Note here q is the state transforming matrix 4. Draw U∼Uniform(0,1). if the probability satisfies, accept Y as the next state.

(4.1.2)Xt+1={Y,U≤α(x,Y),x,U>α(x,Y).

The resulting transition kernel includes both accepted moves and the probability of staying at the current state. It satisfies detailed balance with respect to π, so π is stationary.

For a symmetric proposal, q(y∣x)=q(x∣y), the acceptance probability simplifies to:

(4.1.3)α(x,y)=min{1,π(y)π(x)}.

Thus, moves toward higher-density regions are always accepted, while moves toward lower-density regions may still be accepted. The latter feature prevents the chain from becoming trapped near a single mode.

Proposal tuning A proposal with very small steps tends to have high acceptance but strong autocorrelation. A proposal with very large steps tends to have low acceptance. Good sampling requires a balance between movement and acceptance.

5. Gibbs sampling ​

Gibbs sampling is an MCMC method for a multivariate target distribution π(x1,…,xd) when the full conditional distributions can be sampled.

For a two-dimensional target π(x1,x2), a systematic Gibbs iteration is sample each according to its own distribution π:

(5.1)X1(t+1)∼π(x1∣X2(t)),X2(t+1)∼π(x2∣X1(t+1)).

More generally, update one coordinate at a time from its full conditional distribution:

(5.2)Xk(t+1)∼π(xk∣X1(t+1),…,Xk−1(t+1),Xk+1(t),…,Xd(t)).

For example, when x1 is held fixed, moving from (x1,x2) to (x1,x2′) has transition density π(x2′∣x1). The corresponding coordinate-update kernel satisfies

(5.3)π(x1,x2)π(x2′∣x1)=π(x1,x2′)π(x2∣x1),

because π(x1,x2)=π(x1)π(x2∣x1). Consequently, each coordinate-update kernel leaves π invariant, and no accept/reject step is required: every Gibbs proposal is accepted.

Systematic versus random scan Each individual coordinate update is reversible. A systematic sequence of coordinate updates still leaves π invariant, although the combined full-sweep kernel is not necessarily reversible. Randomly selecting a coordinate at each iteration yields a reversible mixture kernel.

Gibbs sampling can mix slowly when components are strongly correlated, because each move changes only one coordinate. Blocking correlated variables or using more advanced samplers can improve mixing.
